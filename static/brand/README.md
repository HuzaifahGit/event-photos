# Branding

These are neutral placeholders. Replace them with your own artwork (same file names):

- `logo-ring.png`, `logo-ringc.png`, `logo-letters.png`: your event logo (the organiser avatar and the page header)
- `tile.png`: the faint repeating background pattern
- `booth-av.jpg`, `booth-logo.png`: avatar and logo for an imported photobooth gallery
- `vb-av.jpg`: avatar for the shared "team" account (partner crew link)
- `icons/`: small UI icons

Only use logos and images you have the right to publish.
